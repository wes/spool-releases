# Changelog

What changed in each release of Spool.

## 0.1.0

The first build anyone else can run.

Three-pane keyboard-driven UI, multiple accounts with a unified view, IMAP sync
against real servers, full-text search across a quarter-million messages,
conversation threading, HTML mail rendered as styled text, flags, archive and
delete, a command palette, and four themes.

Composing and sending are not here yet. The engine underneath them is built and
tested; nothing in the app reaches it. Mail can be read, searched and filed, not
written.

Requires macOS 13 or later. Universal — Apple silicon and Intel.
